# Minely

Minely is a Windows app for GPU mining, pool balances, and miner status. Earnings are estimates—not guaranteed profits.

## Download

[Download the latest Minely for Windows](https://github.com/landonposuk45-hub/minely-releases/releases/latest/download/Minely-Windows-x64.zip)  
[View release notes](https://github.com/landonposuk45-hub/minely-releases/releases/latest)

## Install

1. Download and extract the ZIP.
2. Open `Minely.exe`.
3. Existing users can use **Check updates** in Minely.

Requires 64-bit Windows 10 or 11. Hardware and miner compatibility vary.

## Support and safety

Minely’s in-app support is a beta. Support messages are not end-to-end encrypted. Never send wallet recovery phrases, private keys, or passwords.

Mining estimates vary with hardware, electricity cost, pool conditions, and accepted work.
